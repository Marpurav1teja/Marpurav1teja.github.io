# Ravi Teja Marpu — Premium Portfolio

Next.js + TypeScript + Framer Motion + Lucide React portfolio for Ravi Teja Marpu.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production / static build

```bash
npm run build
```

The project uses `output: "export"` so the generated `out/` folder can be deployed to static hosting such as GitHub Pages.

## Deploy

- Vercel: import the repository and use the default Next.js settings.
- GitHub Pages: build with `npm run build` and publish the `out/` directory.

Update the LinkedIn/GitHub URLs in `app/page.tsx` if your final profile URLs differ.
